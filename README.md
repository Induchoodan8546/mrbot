# Local AI Chatbot

A production-oriented local AI chatbot built with Python, FastAPI, Ollama, and a layered application architecture.

## Project Status

Phase 1 — Project Initialization

## Objective

Build a maintainable local LLM application rather than a simple model API demo.

The application will support:

* Local LLM inference through Ollama
* Conversation management
* Persistent chat history
* Context-aware conversations
* Streaming responses
* Structured API validation
* Error handling
* Logging and observability
* Automated testing
* Docker-based deployment

## Technology Stack

* Python
* FastAPI
* Pydantic
* Ollama
* SQLAlchemy
* SQLite
* Docker
* pytest

## Development

The project is being developed incrementally through defined engineering phases.

Phase 1 focuses only on project initialization and development environment setup.

## Future Scope

The architecture will eventually provide an extension point for RAG and other LLM capabilities.

RAG is intentionally outside the scope of the current Phase 2 chatbot implementation.
